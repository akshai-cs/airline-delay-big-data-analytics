## Reproduce

From the project root:

```powershell
.\.venv\Scripts\python.exe -m jupyter nbconvert --to notebook --execute --inplace `
  --ExecutePreprocessor.kernel_name=airline-bda `
  --ExecutePreprocessor.timeout=7200 `
  notebooks\Airline_Delay_Analytics.ipynb
```

The notebook expects `flight_data_2024.csv` in the project root and writes all
outputs under `results_analysis/`. It does not modify the source CSV.

## Interpretation notes

- Delays are measured in minutes; negative values mean early.
- A flight is "delayed" at the 15-minute BTS threshold.
- Cancelled flights are excluded from delay-rate denominators; missing delay is
  unknown, not zero.
- Cause attribution covers only delayed departures with positive attributed
  minutes (80.17% of delayed departures). Missing causes are not treated as zero.
- Associations are descriptive, not causal. The ML split is random, not temporal.
- Local single-machine Spark was used; there is no Hadoop, Hive, Kafka, Delta
  Lake, cloud, or database-server component.
